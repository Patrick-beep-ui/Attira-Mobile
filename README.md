# Attira Mobile

Aplicación móvil de Attira con React Native y Expo, organizada con layouts compartidos, navegadores explícitos de React Navigation y pnpm.

Origen: [Attira-AI](https://github.com/Patrick-beep-ui/Attira-AI). La versión PWA se mantiene en su repositorio original.

La implementación y sus instrucciones de ejecución se entregan mediante una PR de migración.
